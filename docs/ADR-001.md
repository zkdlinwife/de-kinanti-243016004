\# ADR-001: Penggunaan Format Penyimpanan Tertutup Vendor



\*\*Status:\*\* diusulkan



\## Konteks



Kampus membutuhkan penyimpanan data akademik dalam jumlah besar. Format penyimpanan harus mudah digunakan, aman, dan dapat diakses dalam jangka panjang.



\## Opsi



\- \*\*A. Format tertutup vendor:\*\* mudah digunakan pada awalnya, tetapi biaya lisensi tinggi dan data sulit dipindahkan.

\- \*\*B. Format terbuka seperti Parquet:\*\* membutuhkan penyesuaian awal, tetapi lebih fleksibel dan tidak terikat vendor.

\- \*\*C. CSV:\*\* sederhana dan mudah dibaca, tetapi kurang efisien untuk data besar.



\## Keputusan



Menggunakan format terbuka seperti Parquet karena lebih fleksibel, hemat biaya, dan tidak terkunci pada satu vendor.



\## Tipe



\*\*One-way door\*\*, karena migrasi data dari format vendor tertutup ke sistem lain membutuhkan waktu, biaya, dan risiko kehilangan data.



\## Konsekuensi



Risiko utama adalah ketergantungan vendor dan kesulitan migrasi. Exit plan: lakukan ekspor data ke format terbuka secara berkala sebelum kontrak atau layanan vendor berakhir.
