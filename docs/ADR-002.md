\# ADR-002: Penggunaan Parquet untuk Data Analitik



\*\*Status:\*\* diusulkan



\## Konteks



Batik Kinanthi membutuhkan penyimpanan data transaksi yang efisien untuk kebutuhan analitik, laporan penjualan, dan analisis perilaku pelanggan.



\## Opsi



\- \*\*A. CSV:\*\* mudah dibaca manusia, tetapi ukuran file besar dan lambat untuk analitik.

\- \*\*B. Parquet:\*\* efisien untuk penyimpanan kolom, mendukung kompresi, dan cocok untuk analitik.

\- \*\*C. Database saja:\*\* praktis untuk transaksi, tetapi kurang optimal untuk arsip analitik skala besar.



\## Keputusan



Menggunakan Parquet sebagai format penyimpanan data analitik karena lebih hemat ruang dan lebih cepat untuk pembacaan kolom tertentu.



\## Tipe



\*\*Two-way door\*\*, karena data Parquet masih dapat dikonversi ke format lain seperti CSV atau database bila kebutuhan berubah.



\## Konsekuensi



Diperlukan library tambahan untuk membaca file Parquet. Exit plan: konversi data ke format lain jika sistem analitik atau kebutuhan bisnis berubah.
